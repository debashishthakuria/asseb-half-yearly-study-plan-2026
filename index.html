How to use each day

Watching is not the same as studying

Three-block routine

  1. Block 1 · 2h: learn concepts from textbook/lecture.
  2. Block 2 · 2h: solve examples and exercises without copying.
  3. Block 3 · 2h: timed practice, closed-book recall, then correction.

Non-negotiables

  • Take a 15–20 minute break between blocks.
  • Keep one error notebook for formulas, reactions and wrong answers.
  • At night, recall the day’s key points without opening notes.
  • Do not let a one-shot replace question practice.
  • Sleep properly before every exam.
